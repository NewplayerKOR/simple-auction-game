# 📖 게임 & 도메인 용어 사전 (Glossary)

> **문서 버전:** v1.0.0  
> **분류:** `common`  
> **최종 수정일:** 2026-11-08  
> **활성 문서 체계:** `.md`  

---

| 용어 (Term) | 영문 (EN) | 설명 및 게임 내 정의 |
| :--- | :--- | :--- |
| **실시간 호가 경매** | English Auction | 현재 최고가보다 높은 금액을 실시간으로 제시하며 경쟁하는 경매 방식. |
| **시작 입찰가** | Starting Bid | 경매 물품이 처음 등장했을 때 제시되는 최소 시작 가격 (기본 감정가의 50%). |
| **호가 단위** | Bid Increment | 기존 최고가에서 추가로 올려야 하는 최소 금액 단위 (예: +100, +500, +1000). |
| **앤티 스나이핑** | Anti-Sniping | 경매 종료 직전(예: 3초 미만)에 입찰이 발생할 경우, 다른 참가자의 응찰 기회를 보장하기 위해 타이머를 강제로 5초로 재설정하는 룰. |
| **낙찰 / 해머** | Hammer / Sold | 타이머가 0초가 되어 최고 입찰자에게 물품 소유권이 이전되고 대금이 결제되는 상태. |
| **유찰** | Passed / Unsold | 경매 제한시간 동안 아무도 시작가 이상으로 입찰하지 않아 물품이 팔리지 않고 라운드가 종료되는 상태. |
| **순자산 가치** | Net Worth | 게임 종료 시 승패를 가르는 최종 점수. `보유 현금 + 획득 아이템 감정가 + 컬렉션 세트 보너스`의 총합. |
| **컬렉션 보너스** | Set Bonus | 특정 카테고리(예: 인상파 회화, 고대 그리스 유물 등)를 2개 이상 모았을 때 추가로 인정받는 가치 가산 비율. |
| **AI 페르소나** | AI Persona | AI 봇의 고유 입찰 성향 (`Aggressive`: 저돌형, `Cautious`: 신중형, `Collector`: 특정 카테고리 집착형). |
