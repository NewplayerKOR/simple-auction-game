# PM 가이드 이전 안내

PM 역할의 현재 권위 문서는 [`../roles/PM.md`](../roles/PM.md)입니다.

모든 PM 세션은 다음 순서로 시작합니다.

1. 루트 `AGENTS.md`
2. `docs/PROJECT_STATE.md`
3. `docs/roles/PM.md`
4. `docs/common/PRD.md`
5. `docs/common/TASKS.md`
6. `docs/common/DECISIONS.md`

이 파일은 과거 경로를 사용하는 세션의 링크 호환성을 위해 유지합니다. 새로운 PM 규칙을 이 파일에 중복 작성하지 않습니다.
