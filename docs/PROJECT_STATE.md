## 5. 현재 권위와 제한

- 제품 요구사항의 권위는 `docs/common/PRD.md`다.
- 미결정 사항은 `docs/common/DECISIONS.md`에서 `OPEN`으로 관리한다.
- 기존 `docs/arch`, `docs/db`, `docs/qa` 문서는 상세 명세로 유지하지만 최신 결정과 충돌하면 재승인이 필요하다.
- 실제 DB가 없으므로 `SCHEMA_MIGRATIONS.md`의 `Applied`는 런타임 DB 적용 증거가 아니라 문서상 모델 변경 이력이다.
- Phase 3는 서버 권위형 FSM, 자금 원장, 재접속·동기화 계약이 승인되기 전 개발하지 않는다.
